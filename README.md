# impara
A simple calculator package.

## Install
    pip install impara

## Use in the terminal
    impara add 10 25            # 35
    impara multiply 4 5         # 20
    impara average 10 20 30 40  # 25

## Use in Python
    from impara import add, multiply, average
    add(10, 25)                 # 35
    average([10, 20, 30, 40])   # 25.0
